## Defects fixed

1. **Queue search discarded workflow-stage restrictions.** In `lunas_backend/src/controllers/incidentController.js`, the Secretary queue used `$or` both for eligible workflow stages and for search. Search replaced the stage predicate. Search is now combined with the existing filter using `$and`, while preserving barangay scope. `incidentValidation.test.js` includes regression coverage and the current Tanod queue states.
2. **Finalization could use a superseded completion inspection or unrelated incident URL.** In `tanodWorkflowController.completeIncident`, lookup now matches the incident URL, requires the incident's current `completionInspection` and `agencyStatus=work_completed`, and retains the verified-result/Secretary checks. Rejected stale attempts leave the inspection unapproved. This enforces existing completion/correction gates; it does not establish institutional closure authority.

The real-MongoDB HTTP integration suite now covers initial assignment, cross-barangay assignment denial, assigned-only start, finding submission, Tanod approval denial, separate Secretary review, agency isolation, invalid completion sequencing, agency progress/completion, final verification, unrelated URL denial, stale-inspection denial, closure and replay denial. Findings were submitted without photo evidence in this suite. It also covers Utility Personnel provisioning/directory isolation, jurisdiction transfer and token revocation.

## Reproduction and evidence

From `lunas_backend/`, start a separate disposable MongoDB server on `127.0.0.1:27119`, set `$env:ACCOUNT_TEST_MONGODB_URI='mongodb://127.0.0.1:27119'`, then run the backend test/lint commands above. The database URI must contain no database name or credentials; the suite enforces this and uses its own disposable database. Never point these tests at application data.

From `lunas_web/`, `npm.cmd run test:e2e` builds and prepares the standalone server. For a browser-only rerun after that preparation, use `$env:PLAYWRIGHT_PORT='3110'; node scripts/run-playwright.mjs`. Fixtures use loopback API port 5119. The runner stops its standalone server after completion.
